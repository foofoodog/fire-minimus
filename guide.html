Welcome to Fire-Minimus

This tablet is set up to be simple, fast, and ready to use for reading, browsing, and media.

Getting Apps

You have two app stores to choose from:
Aurora Store

Your main store for familiar Android apps directly from the Google Play Store (streaming services, music, utilities, and more). You can search and install apps as an anonymous guest without needing a Google account.

F-Droid

An alternative store for free, community-made open-source apps. Great for simple tools, e-readers, offline navigation, and basic games with no logins or ads.

Browsing the Web

Via Browser

A lightweight, fast web browser with built-in ad blocking for everyday browsing.

What About the Amazon Apps?

You might see an Amazon Appstore icon, Kindle, or a banner asking to "Register Device."

You do not need an Amazon account to use this tablet, download apps, or browse the internet. You can safely ignore these Amazon features. Or, if you already have an Amazon account, you can choose to sign in and use them if you'd like. Either way, everything else works right out of the box.
